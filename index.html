장비마당AI 개인정보처리방침

시행일: 2026-08-30 · 최종 개정일: 2026-08-30

장비마당AI(이하 "앱")는 건설장비 임대 사업자의 접수·배차·청구·수금 업무를 관리하는 업무용 앱입니다. 본 방침은 앱이 어떤 정보를 어떤 목적으로 처리하고 어떻게 보관·파기하는지 설명합니다.

1. 처리하는 개인정보 항목

구분항목수집 방법필수 여부
계정 정보 이메일 주소, 비밀번호(암호화 저장), 휴대전화번호 이용자 직접 입력 (회원가입·본인확인) 필수
사업자 정보 상호, 대표자명, 사업자등록번호, 사업장 주소, 업태·종목, 전화번호, 팩스, 이메일, 차고지 주소 이용자 직접 입력 또는 사업자등록증·명함 촬영 인식 선택
업무 데이터 거래처 정보, 현장 정보, 작업 일정, 배차 내역, 청구·수금 내역, 작업 사진 이용자 직접 입력 및 촬영 선택
기기 정보 앱 버전, 운영체제 버전, 푸시 알림 토큰 앱 실행 시 자동 생성 필수
주소록(연락처)은 전화번호에 대응하는 저장된 이름을 화면에 표시하기 위해서만 읽습니다. 읽은 연락처는 기기 메모리에만 머무르며 서버로 전송하거나 저장하지 않습니다.

2. 처리 목적

  • 회원 식별 및 로그인, 비밀번호 재설정
  • 접수·배차·청구·수금 업무 기록의 저장과 조회
  • 온라인 수·발주 기능에서 거래 상대방과의 배차 정보 중계
  • 업무 관련 알림(배차 요청·수락·변경 등) 발송
  • 사업자등록증·명함 이미지에서 업체 정보 자동 입력

3. 기기 권한 사용

권한사용 목적거부 시
연락처 읽기 전화번호에 대응하는 이름 표시, 연락처에서 번호 선택 번호만 표시되며 다른 기능은 정상 동작
카메라 작업 사진 촬영, 사업자등록증·명함 촬영 갤러리에서 이미지를 선택해 대체 가능
사진·미디어 작업 사진 선택 및 갤러리 사본 저장 사진 첨부 기능 사용 불가
마이크 음성으로 접수 내용 입력 음성 입력 대신 직접 타이핑
알림 배차 요청·일정 알림 표시 알림을 받지 못함

4. 정보의 저장 위치

앱의 업무 데이터는 기본적으로 이용자의 기기 안(로컬 데이터베이스)에 저장됩니다. 다음 정보에 한해 클라우드 서버에 저장됩니다.

  • 계정 정보 및 프로필(상호·지역·연락처·차고지 좌표)
  • 온라인 수·발주를 이용할 때, 거래 상대방과 공유되는 배차 정보와 작업 사진
  • 푸시 알림 토큰

온라인 수·발주 기능을 사용하지 않으면 업무 데이터는 기기 밖으로 나가지 않습니다.

5. 제3자 제공 및 처리 위탁

수탁자위탁 업무제공 항목
Supabase Inc. 클라우드 데이터베이스·인증·파일 저장 계정 정보, 프로필, 온라인 수·발주 배차 정보, 작업 사진
Google LLC (Firebase Cloud Messaging) 푸시 알림 발송 알림 토큰, 알림 내용
OpenAI, L.L.C. 사업자등록증·명함 이미지의 문자 인식 이용자가 촬영한 해당 문서 이미지
카카오 주소 검색 및 좌표 변환 이용자가 입력한 주소 문자열

위 목적 외에는 이용자의 개인정보를 제3자에게 제공하지 않으며, 개인정보를 판매하거나 광고 목적으로 사용하지 않습니다.

6. 보유 및 파기

  • 기기 안의 데이터는 앱을 삭제하면 함께 삭제됩니다.
  • 클라우드에 저장된 계정·프로필 정보는 회원 탈퇴 시 지체 없이 파기합니다.
  • 거래 상대방과 공유된 배차 기록은 상대방의 업무 기록이기도 하므로, 탈퇴 후에도 상대방 계정에 남을 수 있습니다.
  • 법령에서 보존을 요구하는 기록은 해당 기간 동안 보관합니다.

7. 이용자의 권리

이용자는 언제든지 자신의 개인정보에 대해 열람·정정·삭제·처리정지를 요구할 수 있습니다. 앱 안에서 직접 수정하거나, 아래 연락처로 요청하시면 지체 없이 조치합니다. 회원 탈퇴는 앱의 [더보기 > 설정] 에서 가능합니다.

8. 안전성 확보 조치

  • 서버와의 모든 통신은 HTTPS 로 암호화합니다.
  • 비밀번호는 복호화할 수 없는 형태로 저장합니다.
  • 백업 파일은 이용자가 정한 비밀번호로 AES-256 암호화합니다.
  • 클라우드 데이터는 계정별 접근 제어(RLS) 로 분리합니다.
